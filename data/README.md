# Données

Le fichier `immobilier_dm_ml.csv` a été fourni dans le cadre du cours et n'est pas redistribué dans ce dépôt.

Pour relancer le notebook, placer le fichier ici : `data/immobilier_dm_ml.csv`.

- **5 000 biens immobiliers**, une ligne par bien.
- **Cible :** `prix_vente_keur`, le prix de vente en milliers d'euros.
- **25 variables explicatives centrées-réduites :**
  - caractéristiques du bien : surface, pièces, chambres, terrain, ancienneté, DPE, parkings, ascenseur ;
  - caractéristiques du quartier : qualité, revenu médian, criminalité, écoles, chômage, pollution ;
  - localisation : distance au centre-ville, aux commerces, à l'école.
